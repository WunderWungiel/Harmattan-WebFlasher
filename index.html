N9 / N950 Web Flasher

WebUSB replacement for Nokia's flasher 3.12 — MeeGo Harmattan, RM-696 and RM-680.

Flashing can permanently damage the device or void its warranty. Keep the battery above ~30 % and never unplug during a flash.

1 Device

Which USB mode is which?
  • NOLO / update mode (0421:0105): the bootloader's flash mode. The usual way in is powering off and plugging in USB while holding a volume key (check your device's flashing guide).
  • Cold flash (0451:d00e, 0451:d009 or 0421:0106): OMAP boot ROM, for a device with a dead bootloader.
  • Phonet (0421:xxxx CDC interface): a running system or the loaded APE algorithm. Identify works here.

Use a file instead of (or in addition to) the one inside the FIASCO. A supplied file replaces FIASCO images of the same type. ape-algo may be a FIASCO or a plain image.

Loader images (2nd, ape-algo) are used automatically to get the phone into flashing mode; they are never flashed. For the N9, load the main FIASCO and the eMMC FIASCO together.

Erasing runs before the images are flashed. MMC erases the eMMC. User data erases the eMMC and swap and resets the device lock, so ticking both erases the MMC twice.
